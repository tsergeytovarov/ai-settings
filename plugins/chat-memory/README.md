# chat-memory

Плагин Claude Code: боковая панель «Память чата» и две кнопки в полосе над строкой ввода.

## Панель

- **Память**. Каждый раздел в своём блоке с цветной рамкой: цель, решения, выводы, открытые вопросы, следующий шаг. Внутри блока markdown, тем же оформлением, что ответы в чате. Пустые разделы не показываются.
- **Цифры**: сколько потрачено и сколько в час, сколько идёт сессия, запросов и изменённых файлов, заполнение контекста, лимиты на 5 часов и неделю со временем до сброса. В десктопе вкладка рисуется одной SVG-картинкой: раскладка своя, ничего не наезжает. В терминале — строками.

Панель открывается при старте сессии и командой `/chat-memory`, листается самим десктопом.

## Кнопки в полосе над вводом

- **«↻ Память»**: обновить память.
- **«🗜 Сжать»**: обновить память и сжать чат. Свой хук `session.compact` движок для собственного вызова плагина пропускает, поэтому кнопка сама передаёт память в инструкции компакта. Если прямой `$.session.compact` отказал (движок считает, что идёт ход, а нажатие кнопки может так считаться), кнопка ставит `/compact` с теми же инструкциями в очередь, и он выполнится, когда сессия освободится. Настоящая причина отказа уходит в debug-лог. Тост показывается, только если не вышло и так, и в нём текст ошибки от движка.

Полоса всегда на экране. Если её рисует ещё и `context-weather`, кнопки встают справа от лимитов: чужая полоса занимает место, которое оставили кнопки, а кнопки не сжимаются.

## Когда обновляется память

Только по кнопке «↻ Память» и перед компактом: `/compact`, автокомпакт, «🗜 Сжать». Перед сжатием память догоняет чат и уходит в инструкции компакта, чтобы сводка не потеряла решения и выводы.

Сжимает Haiku 5.5 (`claude-haiku-5-5`) через `$.model.complete`: получает прошлую память и только новые сообщения.

## Полоса по цепочке

Полосу рисуют по цепочке: каждый плагин берёт то, что нарисовали плагины под ним (`next(e)`), и ставит рядом своё. Когда под плагином никто не рисует, `next(e)` отдаёт служебный элемент `{ type: 'engine' }`. Вкладывать его в своё дерево нельзя: движок отклоняет такое дерево и не рисует полосу вовсе. Поэтому оба плагина его отбрасывают.

Закреплённого низа у панели в движке нет, а свой фрейм с прокруткой в десктопе ломается. Поэтому кнопки живут в полосе, а не в панели.

## Установка

```bash
claude plugin marketplace add ~/work/ai-settings/plugins
claude plugin install chat-memory@popovs-plugins
```

## Разработка

- `hooks/digest.ts` — промпт для Haiku, разбор ответа, разделы памяти, инструкции компакту.
- `hooks/layout.ts` — статистика по транскрипту, форматирование.
- `hooks/chart.ts` — SVG вкладки «Цифры».
- `hooks/register.tsx` — хуки, полоса, панель.
- Проверка: `claude plugin validate .` и `claude plugin test .`
