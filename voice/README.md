# voice

Мой голос для агентов. Отсюда стиль берут все скиллы, которые пишут тексты от моего имени: задачи в Трекере, сообщения в Mattermost и мессенджерах, посты, письма.

Правила в `docs/ai/writing-voice.md` только запрещают. Голос задают примеры, поэтому основа здесь — корпус настоящих текстов.

## Структура

Всё содержательное лежит в `private/`. Папка в `.gitignore`: там переписка с коллегами, а репа публичная.

- `private/profile.md` — приёмы по регистрам с цитатами. Главный файл для скилла.
- `private/zadaniya.md` — мои ответы на 14 рабочих ситуаций.
- `private/telegram.md` — посты из канала и мои сообщения из лички.
- `private/mattermost.md` — мои сообщения из тредов и личек, без агентских тредов и вставок.
- `private/corrections.md` — пары «было → стало»: агент написал, я поправил. Отсюда раз в пару недель выжимаются правила в `profile.md`.

Читает всё это скилл `skills/popovs/my-voice`.

## Правило для корпуса

Сюда идёт только текст, который я написал сам. Всё, что правила нейросеть, портит выборку.
