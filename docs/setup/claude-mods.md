# Моды Claude Code: полоса, предохранитель, память, звуки

Три плагина для Claude Code, которые я сделал под себя и теперь раздаю. Работают в десктопе (вкладка Code) и в терминале. Ставятся из этого репозитория одной командой на каждый, сносятся так же.

![Полоса над вводом: погода контекста, лимиты, кнопки «Память» и «Сжать»](img/claude-mods-band.png)

## Что есть

| Плагин | Что делает |
| --- | --- |
| `cockpit` | Полоса над строкой ввода: погода контекстного окна (от солнца до урагана по мере заполнения), лимиты на 5 часов и неделю двумя маленькими Claude в кольцах, кнопка «Сжать». Плюс предохранитель: перед опасной командой останавливает вызов, играет сирену и спрашивает, что делать. |
| `chat-memory` | Боковая панель «Память чата»: цель, решения, выводы, открытые вопросы. Сжимает их Haiku по кнопке «Память» и перед каждым компактом, чтобы сводка не теряла решения. Вкладка «Цифры»: сколько потрачено, сколько идёт сессия, контекст, лимиты. |
| `sounds` | Звук, когда сессии нужен человек: капля — ответ дописан, «кря» — модель спрашивает или ждёт разрешения. Можно уйти в другое окно и вернуться на звук. |

Ставить можно любой набор. Главный — `cockpit`.

## Требования

- Claude Code 2.1.287 или новее: моды появились в этой версии. Версию показывает `claude --version`.
- `sounds` работает только на macOS: звук играет `afplay`.
- Лимиты движок отдаёт для подписки Claude. На ключе API кружков с лимитами, скорее всего, не будет — не проверял.
- `chat-memory` тратит немного токенов Haiku на каждое обновление памяти. Само по себе оно не обновляется: только по кнопке и перед компактом.

## Установка

```bash
claude plugin marketplace add tsergeytovarov/ai-settings
claude plugin install cockpit@popovs
claude plugin install chat-memory@popovs
claude plugin install sounds@popovs
```

Лишнее не ставь. Заработает в новой сессии: открытые сессии плагины не подхватывают.

Обновиться до свежей версии:

```bash
claude plugin marketplace update popovs
claude plugin update cockpit@popovs
```

С остальными плагинами то же самое.

## Предохранитель

Ловит перед выполнением:

- `rm -rf` и `rm -r` (кроме `/tmp` и scratchpad), `git push --force`, `git reset --hard`, `git clean -f`, откат правок, `git branch -D`, `curl … | bash`, `sudo`, удаление в kubectl и yc, `DROP`, `TRUNCATE`, `DELETE` без `WHERE`;
- в MCP — удаление, массовые правки, разрушительный SQL, посты в Mattermost, письма, открытие доступа на Google Drive, удаление артефакта.

![Предохранитель: вопрос и красная карточка над вводом](img/claude-mods-airbag.png)

Что видно, пока висит вопрос:

- красная карточка над вводом: что произойдёт, зачем модель это делает, что затронет (для удаления — каждый путь с числом файлов и размером) и сама команда;
- вопрос с тремя ответами: «Выполнить», «Разрешать до конца сессии», «Запретить».

При запрете модель получает объяснение и не повторяет без просьбы. Закрытый диалог тоже считается запретом.

Если команду и так запрещает правило `permissions.deny` из твоих настроек, предохранитель молчит: движок откажет сам.

В автозадачах отвечать некому, поэтому разрушительное там запрещается сразу, а посты и письма проходят.

Если какое-то правило мешает, жми «Разрешать до конца сессии»: до конца этой сессии про такое больше не спросит.

## Если стоит вместе

- `cockpit` и `chat-memory`: кнопка «Сжать» будет одна, от `chat-memory`, — она перед сжатием ещё и сохраняет память.
- `sounds` и `cockpit`: на вопрос предохранителя играет только сирена, «кря» молчит.
- Десктоп сам показывает баннеры macOS, когда чат закончил или ждёт ответа. Чтобы звук не двоился со `sounds`, выключи звук уведомлений в настройках десктопа.

## Удалить

```bash
claude plugin uninstall cockpit@popovs
claude plugin uninstall chat-memory@popovs
claude plugin uninstall sounds@popovs
claude plugin marketplace remove popovs
```

## Где код

Исходники лежат в `plugins/` этого репозитория, у каждого плагина свой README. `cockpit` собран из `context-weather` и `airbag` скриптом `plugins/cockpit/scripts/sync.py`.
